# Sales Analytics Dashboard

A simple Streamlit web app that uses an Excel file as its datasource to display sales data analysis and reporting.

## Architecture

```
.
├── app.py              # Main Streamlit application
├── sample_data.py      # Generates the sample Excel dataset
├── data/
│   └── sample_sales.xlsx   # Sample sales data (250 rows, generated)
└── requirements.txt    # Python dependencies
```

**Stack:** Python · Streamlit · pandas · openpyxl · Plotly

## Setup & Running

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate sample data (run once)
python sample_data.py

# 3. Start the app
streamlit run app.py
# Opens at http://localhost:8501
```

## Features

- **File upload** — upload any `.xlsx` file via the sidebar; falls back to the sample dataset automatically
- **Sidebar filters** — filter by Region and Product; all views update live
- **Overview tab** — key metrics (revenue, profit, units, top product/region) + data preview
- **Charts tab** — monthly revenue trend, revenue by region, revenue by product, units sold pie chart
- **Data tab** — full filtered table + CSV download button

## Sample Dataset

Generated by `sample_data.py`. Contains 250 rows with columns:
`Date`, `Region`, `Product`, `Sales Rep`, `Units Sold`, `Revenue`, `Cost`, `Profit`

Covers Jan–Dec 2024 across 4 regions (North, South, East, West) and 6 products.

## Bringing Your Own Data

Upload any `.xlsx` file via the sidebar. The app expects at minimum these column names for full functionality:
- `Date` — date values
- `Region` — categorical string
- `Product` — categorical string
- `Revenue` — numeric
- `Units Sold` — numeric

Other columns will be included in the Data tab but won't drive the charts.
